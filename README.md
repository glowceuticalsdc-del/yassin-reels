# Yassin Educational Reels

Deploy this folder to any HTTPS static host such as GitHub Pages, Netlify, or Vercel.

Files:
- index.html
- manifest.webmanifest
- sw.js
- .nojekyll

Recommended: GitHub Pages from the repository root.

Notes:
- YouTube embeds require internet access.
- Individual YouTube videos can still block embedding at the publisher level.
- The app skips a blocked video instead of breaking the whole feed.
